Whole-row link (stretched-link)

Put the class on the row's main link. A click almost anywhere in the row opens it (no JavaScript); ctrl/middle-click, the status-bar URL and keyboard focus behave like a real link. Other links in the row (a pilot's name, say) stay clickable. The rows of the demo table above use it; the callsign is the target. Do not use it in a row with no single obvious target (a kills table), or twice in one row.

{% verbatim %}<tr>
  <td><a class="stretched-link" href="{% url 'web:sortie-detail' s.pk %}">{{ s.spawned_at|utc }}</a></td>
  <td><a href="{% url 'web:player-detail' s.player_id %}">{{ s.name_at_time }}</a></td>   {# still its own link #}
</tr>{% endverbatim %}

Flavor text

{% verbatim %}{% flavor "top_pilot" mission.pk %}              {# several variants per spot, stable per seed #}
{% sortie_flavor sortie as quip %}{% if quip %}...{% endif %}{% endverbatim %}

A short quip at a few highlight spots only (hall of shame, notable sortie outcomes, the last mission's top pilots). The variant is chosen by hashing the spot name and the seed (an object id), so a page never changes on reload. Variants live in il2ks/web/flavor.py; keep them kind, light and free of politics.
