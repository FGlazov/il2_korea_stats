{# il2ks-template: templates/il2ks/components/columns_picker.html v1 - copy this line along when you override #} {% load i18n %}{% comment %} columns_picker.html ({% columns_picker optional_columns %}): the collapsible "Extra columns" of a list page, for inside a {% filter_bar %}. One checkbox per optional column, all shown at once in a compact grid (no menu to scroll), all named `cols`: the form submits ?cols=a&cols=b (the page also reads ?cols=a,b). Works without JS (the Apply button submits); with htmx a change refreshes the results. It starts open when a column is ticked (so a no-JS submit or a reload stays open); hx-preserve keeps the element, with its open state, while the region is swapped (il2ks.js puts the focus back on the clicked checkbox and the table's horizontal scroll where it was). The summary is a button-like control in the same row as the filters (chevron, count chosen/available such as 5/21, kept right by il2ks.js; see site.css); the checkbox grid opens below as a full-width panel of the bar. Context: options (list of (key, label, hint, checked)), any_checked, chosen (number ticked). {% endcomment %}
