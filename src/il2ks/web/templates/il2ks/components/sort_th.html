The link keeps the other query parameters, drops `page`, and toggles ?sort=field / ?sort=-field. The view must whitelist sortable fields. Context: label, numeric (right-aligned column), direction ("asc", "desc" or ""), aria_sort, href, hint, hint_id. The hx-get makes it swap the surrounding {% results_region %} (hx-target, hx-select, hx-swap and hx-push-url are inherited from it); without htmx it is a plain link. A hint (see col_th.html) is described by the link itself (aria-describedby) and shown when the header is hovered or the link focused; the marker beside the link shows it on tap. {% endcomment %}{{ label }}{% if hint %}{% include "il2ks/components/col_hint.html" %}{% endif %}
