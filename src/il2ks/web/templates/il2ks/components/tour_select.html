Other query parameters are kept as hidden fields (never ?page=, so a new tour starts at page 1). With htmx it submits when the choice changes; without JS the Apply button does. Inside an existing {% filter_bar %} use {% filter_select "tour" _("Tour") tour_options all_label=_("All time") %} instead (il2ks.queries.tours.tour_options). Context: tours (newest first), selected_id (the chosen tour's id or ""), action (current path), hidden ((name, value) pairs).
